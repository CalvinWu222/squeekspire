# 设计稿 v3：《Squeekspire》（定名）
已定：名称 Squeekspire；首个职业 Zoomie Gremlin（暴走小鬼）；未绑钱包玩家显示 guest+数字（如 guest1234）；隐藏组合首发现广播已删除。
推荐理由：一眼看出是"Squeek + 杀戮尖塔(Spire)"，和 Exsqueektion、Squeektoshi 同一种谐音梗，好记好搜。
首发职业：**Zoomie Gremlin（暴走小鬼）**——半夜三点发疯狂奔的仓鼠，越跑越停不下来，招式靠"连跑"叠倍率，口头禅 "gm, I have not slept"。
（其余两职业后续：Seed Hoarder 囤粮怪、Professional Napper 职业睡王）
不写代码，仅设计。全部仅 Sepolia，不涉真实资产。

## 一、一句话
每天的地牢就是仓鼠昨夜的跑步曲线：它跑得越疯，今天的怪越凶、宝越好。白天仓鼠睡觉，你下地牢。

## 二、核心循环（每日一局，约 25 分钟）
1. 每天 00:00 UTC 锁定"昨夜"（前 24h 已结算数据），生成当日地牢；日期、种子和每日次数均按 UTC 日界线计算。
2. 地图 = 24 个小时桶组成的分支路线（每格一个时辰）。
3. 选起始牌组（"跑者/囤粮/沉睡者"三职业）→ 战斗/事件/商店 → 3 幕 Boss。
4. 提交操作记录 → 重放验证 → 进入当日排行榜；之后可无限练习。

## 三、数据→机制映射
| 数据 | 机制 |
|---|---|
| settlements 每小时 workAdded | 该格类型：高=狂奔层（精英/双倍掉落），中=普通战，0=沉睡层（休息/商店） |
| 24h 总 workAdded vs 近7晚中位数 | 全局难度系数（呼应"难度调整"）；远低于中位数→"冬眠日" |
| completedBlockCount | 卡池稀有度权重（出块越多，稀有卡越多） |
| settlementCount / activeRoundCount | 事件格数量；每个 round = 一次"结算"回合奖励 |
| 峰值 rpm / speedMmPerSecond | Boss 速度（每回合行动次数）与"冲刺"词条 |
| blockHeight 尾数 / blockProgress | Boss 种类选择、遗物出现位置 |
| BatchSettled txHash + settledThroughRound | 随机种子（公开可复算） |
| sqkMintedBaseUnits | 当日"SQK 金币"总量，商店价格通胀/通缩 |
| 实时 coreStatus SPINNING | 仅练习模式：每回合 +1"轮子之力"能量；排行榜不受影响 |

## 四、卡牌/遗物/敌人示例
卡牌：
- 【踩轮】1费 造成伤害=当前格 workAdded/100。
- 【合并】把两张同级牌合为一张高一级（+10%数值），每幕限 1 次（合并冷却），上限 Lv100。
- 【质押】放弃本回合抽牌，下回合力量 W=P+S×(1+P/1000)/c 的简化版加成。
- 【结算】延迟牌：3 回合后（"10 分钟一轮"）一次性兑现累积伤害。
- 【冬眠】沉睡者专属：跳过回合，回复并叠"梦境"层。
- 【预言：吱或睡】（致敬 Squeek or Sleep）猜下张牌类型，猜中翻倍。
遗物：WHEELY9000 齿轮（每 3 张牌 +1 能量）、Genesis 种子（开局多一张稀有）、直播摄像头（敌人意图全显示）、Aura 光环（连胜加分）、起名牌（给一张卡改名后永久+1，致敬起名屋）、白皮书残页（致敬 Wheelpaper，揭示下一格）。
敌人：Oracle 审判者（拒绝你最高费的牌，"oracle rejected"）、结算队列蛇（每回合排队叠攻击）、难度调整者（你越强它越强）、陈旧数据幽灵（staleAfter 120s，回合超时掉血）、Boss：失眠的 Squeektoshi（rpm 越高行动越多）。

## 五、仓鼠睡觉处理
- 排行榜只用已结算的昨夜数据，白天任何时间玩都公平。
- 当晚几乎没跑 → "冬眠日"：地图起雾、梦境卡池、分数系数 ×1.2，鼓励大家照样来。
- API 无数据/oracle 异常 → 回退前一天地牢并公告。

## 六、每日排行榜
分数 = 层数×100 + 剩余 HP + Boss 击杀奖励 × 难度系数。榜单：今日、连续天数、"冬眠日之王"。每天 00:00 UTC 结算，日榜键使用 UTC 日期。所有玩家等权，无付费加成。

## 八、反作弊与种子可验证
- 确定性引擎：种子 + 地图数据全部来自公开 API/链上事件，任何人可复算地图。
- 提交整局操作序列，服务器重放得分，不信任客户端分数。
- 正式局次数按浏览器本地档案限制，每个 UTC 日一次；开始即记录，放弃也算，清除本地数据可重置此限制。
- 正式榜不请求签名：游客名与钱包地址均为自行提供的显示标签，不证明账户所有权或身份。
- 已实现服务器重放校验得分与每 IP 提交/读取频率限制。这些是基础滥用限制，不提供跨身份参赛限制、设备指纹、人工审榜或身份认证。

## 十、数值膨胀与上瘾循环（v2 新增，已过 2 轮挑刺）
### 计分：吱数 × 倍率（Balatro 式）
- 每次出牌产出 **吱数(Squeeks)**，遗物/连招提供 **加倍率(+Mult)** 与 **乘倍率(×Mult)**，每场战斗结算一次：吱数 × 倍率 = 本场分。日榜分 = 各战累加 × 难度系数。
- 数字从几十滚到 10^6~10^12，超过 1e6 起用科学计数 + "SQUEEK!" 爆字特效、屏幕震动、轮子音效加速。
- **连跑链(Zoomie Chain)**：同回合连续出同类牌，每张 ×1.1 叠乘；断链清零。首发职业核心。
- **暴走时辰(Zoomies Hour)**：昨夜跑量最高的 1~3 个小时格 = 头奖格，该格内所有 ×Mult 再 ×2，金色地图格；所有人同一天同一位置，社区可讨论"今天第 7 格炸了"。
- **稀有羁绊**：约 8 组隐藏组合（如 结算延迟牌 + Oracle 拒绝 → "双重结算" 伤害×3），只在本人局内弹出提示，无全服广播。
### 上瘾循环
- **再来一局**：练习/无尽模式一键重开，开局 3 秒入战。
- **差一点**：结算页显示"距上一名还差 X 吱""Boss 剩 3 HP"，并给出本局最大单次数字。
- **5 分钟无尽模式**：独立"无尽榜"，可无限重玩，用当日种子，难度每层 ×1.15 直到暴毙，比最高数字。
- **局外解锁（不破坏日榜公平）**：解锁只给外观（轮子皮肤、爆字字体）、图鉴、以及**横向替代牌**；**日榜正式局所有人用同一套固定基础卡池**，解锁内容只在练习/无尽可用。
- **连续打卡**：每日正式局连签天数显示在榜（火焰图标），断签不扣分，只是归零称号。
- **每日成就**：3 个当日小目标（如"单击过 1e8"），纯称号。
- 明确不做：抽卡付费、开箱、可交易奖励、任何真钱或可兑换代币——只有测试网和荣誉。

## 十一、风险
- 平衡：数据极端（如一晚 0 或暴涨）可能让难度失控 → 系数夹在 0.7–1.5。
- 被看成"API 包装"：靠"曲线即地图"和可感知规则化解，需在演示中强调。
- 与 Exsqueektion/Squeek race 同属游戏类，需突出卡牌策略差异。
- 排行榜作弊与冷启动人数少；美术工作量。
