角色：【批】Squeekchain 开发/评审（严苛）｜【设】游戏设计师｜【玩】杀戮尖塔老玩家｜【链】链上 coder/degen（仅 Sepolia）
实测数据（2026-11-04 00:43 北京时间）：coreStatus=IDLE，rpm 0；blockHeight 7661，settledThroughRound 1168；24h workAdded 8725、settlementCount 136、activeRoundCount 23、completedBlockCount 853；单次结算 workAdded≈570、completedBlockCount≈55，带 sqkMintedBaseUnits。

## 第 1 轮：初版"每日种子地牢"
【设】昨晚 round 数据哈希成种子，生成当天地图，全服同图，比层数。
【批】种子=哈希，仓鼠就只是随机数发生器，换成 Math.random 体验不变 = 薄包装，拒。
【玩】每日挑战可以，但只有"同一张图"不够，要有当天可感知的规则变化。
【链】数据可验证：用 BatchSettled 的 txHash + settledThroughRound 做种子，任何人可复算。
→ 改进：数据不仅做种子，还要直接变成"可读的规则"。

## 第 2 轮：数据→规则
【设】昨夜 24 个小时桶 = 地图 24 格"时辰"；每小时 workAdded 高的格子是"狂奔层"（精英/高掉落），0 的是"沉睡层"（安全休息/商店）。总 work 决定 Boss；completedBlockCount 决定当天卡池稀有度；峰值 rpm 决定 Boss 速度。
【批】好一点。但玩家看得懂吗？仓鼠睡了白天怎么办？
【设】开局显示"昨夜跑步曲线"就是地图本身——曲线即关卡。白天仓鼠睡觉正好是玩的时间；若当晚几乎没跑，触发"冬眠日"特殊规则（迷雾、梦境卡），而不是坏掉。
【玩】曲线=地图很直观，像看天气预报再出门。
【链】小时桶接口现成；冬眠日阈值用近 7 晚中位数。
→ 遗留：怎么体现"实时"仓鼠又不要求在线？

## 第 3 轮：实时元素但不强制在线
【设】"轮子能量"：打牌时若此刻仓鼠 SPINNING，每回合 +1 能量的"轮子之力"（可选加成，只影响非排行榜的练习/无尽模式），排行榜模式只用已结算数据，保证公平。
【批】否则夜猫子占便宜，分开得对。
【玩】再加"难度调整"：昨夜跑得越多，今天敌人越强但遗物越好——呼应区块难度调整。
【链】Squeek NFT 合并机制可做卡牌升级：两张同级卡合成升一级 +10%，有冷却（每局限 N 次），上限 100 级 → 比照官方规则。
→ 遗留：NFT/SQK 如何接入又不变成 pay-to-win。

## 第 4 轮：生态钩子与反作弊
【批】持有 NFT 加战力会被说是刷/P2W，也挡人。
【设】默认零门槛。连钱包（仅 Sepolia）只换外观："你的 Squeek 当主角皮肤"，NFT 等级决定解锁的起始牌组种类（横向不纵向）。
【链】排行榜：客户端上传操作序列（种子+每步选择），服务端/任何人用同一确定性引擎重放校验分数；排行榜签名钱包（无授权、只签消息）。每日 Top 发 Sepolia 徽章 NFT（可选，后期）。不承诺 WL。
【玩】出牌节奏要 20–30 分钟一局，每天 1 次正式局，可无限练习。
【批】可以接受。风险：IMD swarm 构建、和 Squeek Den/Exsqueektion 同属游戏类但玩法不撞。

## 补充圆桌：数值膨胀与上瘾玩法（2 轮）
### 第 1 轮
- 苛刻 DEV 评审：大数字很爽，但如果分数膨胀和仓鼠数据无关，就是"Balatro 换皮"。日榜如果局外解锁影响强度，就不公平，直接毙。无钱包正式榜会被刷。
- Balatro/杀戮尖塔玩家：+Mult/×Mult 分层必须清楚，否则数字乱涨没有策略感；连招要有断链风险，不然没张力；无尽模式没有上限会被一个无限连招打穿。
### 修改
- 头奖格绑定昨夜最高跑量时辰（暴走时辰），膨胀来源=仓鼠数据。
- 日榜固定基础卡池，解锁只进练习/无尽，且为外观/横向牌。
- 连跑链断链清零；无尽每层 ×1.15 难度，单局限时 5 分钟。
- 无钱包：匿名 ID 签名提交 + 每日 1 次 + 频控 + 重放 + 前 25 抽查 + "未验证"标签。
### 第 2 轮
- DEV：现在"仓鼠跑得疯→今天能炸大数"是可感知、可截图传播的，这是 novel 点；认可。仍担心刷号，接受"未验证"标签作为 v1 折中。
- 玩家：分数可读、有爆点、有差一点，有再来一局理由；建议 1e6 后用科学计数防溢出（已采纳）。隐藏羁绊首发现广播有收集欲。
- 结论：通过，进入待用户确认。
